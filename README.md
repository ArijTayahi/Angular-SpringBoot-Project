🧑‍💼 Employee & HR Management System
📌 Project Overview

This project is a web-based Human Resources Management System designed to manage employees, tasks and their progress, and HR processes.
It is developed using Angular for the frontend and Spring Boot for the backend, following a RESTful architecture.

🎯 Project Objectives

Centralize employee management

Track tasks and monitor their progress

Improve HR process management

Provide role-based access and dashboards

👥 User Roles

Admin

HR Manager

Manager

Employee

⚙️ Features
👤 Employee Management

Add, update, and delete employees

View personal and professional information

Assign employees to departments and positions

📋 Task Management

Create and assign tasks

Track task progress (To Do / In Progress / Done)

Manage priorities and deadlines

View task history per employee

📈 Progress Tracking

Dashboards for task monitoring

Progress statistics

Global view by employee or team

🏢 HR Management

Department management

Leave management

Contract tracking

Employee evaluations
